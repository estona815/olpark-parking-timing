# 올팍 주차 타이밍 (Olympic Park Parking Timing)

한국체육산업개발(주) 공공데이터(공공데이터포털)로 만든 올림픽공원 공연일·주말 주차 혼잡 예보 웹앱입니다.

- 사용 데이터: 영문 공연정보(15149169), 주차장 혼잡도 정보(15164156), 월별주차현황(15131671), 올림픽공원 입출차 정보(15138735)
- 원자료는 재배포하지 않고 집계값(`data.json`)만 포함합니다.
- 예보는 과거 패턴 × 계절 지수의 참고값이며 실시간 정보가 아닙니다.

2026년도 한국체육산업개발 공공데이터 활용 경진대회 출품작.
